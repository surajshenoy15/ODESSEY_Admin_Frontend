# BNMIT ODYSSEY Admin Portal

React + Vite + Tailwind + Lucide administration portal.

Important screens include dynamic sports/cultural event setup, registration/payment review, side-by-side bonafide and student-photo verification, QR attendance, duplicate-check-in protection, fixture publication, live-stream management, certificate eligibility override/generation, reports, admins, audit logs and email logs.

Setup:

```bash
npm install
copy .env.example .env
npm run dev -- --port 5174
```
